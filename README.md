# 仁王2 新宿地图 / Nioh2 Shinjuku Map

r53 正式安装包请在 **[Releases 下载区](https://github.com/2496239123/Nioh2-Shinjuku-Map/releases)** 下载。

## 选择版本

| 安装包 | 适合的玩家 | 加载方式 |
|---|---|---|
| `Nioh2_Shinjuku_r53_Map_Full_20261020.zip` | 单独安装地图 | 包内独立地图加载器 |
| `Nioh2_Shinjuku_r53_Plugin_Full_20261020.zip` | 已使用 API v1 统一加载器 | 保留已有 `dinput8.dll`，加入 `plugins/ShinjukuMap.dll` |

两个包均为完整地图资源，二选一安装，不需要先安装旧版。插件版不附统一加载器；LB+B 和语音模组也不在包内。

## 手动安装

1. 完整退出游戏。
2. 按照压缩包内 **先读我_手动安装.txt**，将相应目录与文件复制到 `nioh2.exe` 所在目录并合并。
3. 已有个人键位、配置或自定义贴图时，先保留自己的文件，再按包内升级说明处理。
4. 重新启动游戏。贴图需要刷新时按 F10；后台程序更新必须重启游戏。
